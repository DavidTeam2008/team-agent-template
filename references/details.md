# 团队规则细则

> `AGENTS.md` 的补充材料。只在需要时读取，不要求每次会话加载。

## MEMORY 决策模板

每条决策至少记录：

```markdown
## YYYY-MM-DD · 决策标题

- 背景：
- 决策：
- 备选方案：
- 影响/风险：
```

写入项目 `MEMORY/decisions.md`；跨项目团队决策写团队根 `MEMORY/decisions.md`。

## Wiki 页面规则

- 只写可跨任务复用的结论；一次性任务不写。
- 每页保留来源和最后更新时间。
- 与当前事实冲突时，以代码或原始资料为准并更新页面。
- 归档保留原页面，写明原因和替代页面（如有）。
- 项目知识放项目 `Wiki/`，跨项目知识放团队根 `Wiki/`。
- `index.md` 条目：`- [标题](路径) — 一句话摘要（最后更新：YYYY-MM-DD）`。

建议目录（按需创建）：`index.md`、`concepts/`、`entities/`、`analyses/`、`archive/`。

## 中国大陆镜像与 CDN

- 安装依赖、下载工具、拉取镜像时优先稳定、活跃、可信的国内镜像，并说明来源。
- 国内镜像版本落后、内容缺失或有供应链风险时明确提醒，必要时用官方源校验。
- 单文件 HTML CDN 首选：`https://cdn.bootcdn.net/`、`https://cdn.staticfile.net/`
- 兜底：`https://cdn.jsdelivr.net/npm/`、`https://unpkg.com/`，使用时说明大陆可能不稳定。
- Tailwind Play CDN 仅用于原型；图标优先内联 SVG，使用图标库时选较新版本。

## 前端/客户端质量检查

- 可访问性：对比度、点击区域、动态字体、VoiceOver/TalkBack。
- 性能：启动、滚动、包体积、内存无明显回归。
- 目标浏览器/机型矩阵：按项目定义；未定义时至少覆盖主流浏览器和最低支持机型。
- 设计系统：优先复用现有组件，不擅自引入新的 UI 框架或图标库。
- 深色模式、响应式、安全区、键盘和权限按平台检查。
- React Native/原生混合项目注意导航、权限、键盘、字体、安全区、后台行为和原生模块版本。

## 开源方案评估

采用开源方案前检查维护活跃度、许可证兼容性和项目匹配度。技术选型做对抗性审查，至少覆盖失败模式、扩展性、成本、安全、迁移和供应商锁定。

## 验证示例

| 变更类型 | 最低验证 |
| --- | --- |
| 文档/配置 | 链接、渲染、字段和事实核对；必要时运行校验脚本 |
| 代码 | 项目已有的 lint、类型检查、测试和构建 |
| UI/交互 | 本地启动并实际操作主路径和关键边界；必要时真机/多浏览器 |
| 数据/迁移 | 隔离环境验证迁移、回滚和数据一致性 |

未运行或无法运行的验证必须写“未运行”及原因。
