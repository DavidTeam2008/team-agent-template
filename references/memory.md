# MEMORY 细则

## 何时写

- 写关键决策、持续事实、未完成事项和交接状态；临时讨论、未确认推测不写。
- 项目决策写项目 `MEMORY/`；跨项目决策写团队规则所在目录的 `MEMORY/`。
- 同一信息只存一处，其他位置用链接。

## 目录与索引

- `MEMORY.md`：索引，一行一条：`- [标题](文件) — 一句话（YYYY-MM-DD）`
- `decisions.md`：已确认决策
- `todos.md`：未完成事项、阻塞、下一步
- `facts.md`：稳定事实（环境、外部依赖、约束；不含密钥）

按需创建，不要求一次建全。易变状态不写进 `AGENTS.md`。

## 决策模板

```markdown
## YYYY-MM-DD · 决策标题

- 背景：
- 决策：
- 备选方案：
- 影响/风险：
```

只记已确认决策；被推翻的决策保留，并标注替代项和日期。

## 交接检查

- `MEMORY.md` 能说明目标、已完成、未完成、阻塞和下一步。
- 更新时间与负责人明确。
- 长任务另存计划、检查点和验证记录，不只留在对话里。
