# 前端 / 客户端细则

## 质量检查

- 可访问性：对比度、点击区域、动态字体、VoiceOver/TalkBack。
- 性能：启动、滚动、包体积、内存无明显回归。
- 目标矩阵：按项目定义；未定义时至少覆盖主流浏览器和最低支持机型。
- 设计系统：复用现有组件，不擅自引入 UI 框架或图标库。
- 深色模式、响应式、安全区、键盘、权限按平台检查。
- RN/原生混合：导航、权限、键盘、字体、安全区、后台行为、原生模块版本。

## 依赖与镜像

- 默认官方源，锁定版本并校验完整性（lockfile、checksum、签名）。
- 需要镜像时选稳定、活跃、可信的来源，说明来源和风险；镜像缺失或版本落后时用官方源校验。
- 不安装来源不明、长期未维护或许可证不兼容的包。

## CDN 与原型

- 生产环境优先本地打包资源；使用 CDN 时锁定版本，必要时加 SRI。
- Tailwind Play CDN 只用于原型。
- 图标优先内联 SVG；使用图标库时选维护活跃的版本。
- 简单网页/原型默认单文件 HTML + Tailwind + 本地或可信 CDN。

## 开源方案评估

采用前检查维护活跃度、许可证兼容性和项目匹配度。技术选型做对抗性审查，至少覆盖失败模式、扩展性、成本、安全、迁移和供应商锁定。
